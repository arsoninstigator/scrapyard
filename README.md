## website development

to run the website locally and test changes 
- download nodejs (https://nodejs.org/)
- download git (https://git-scm.com/)
- clone repository using git (in the terminal, run `git clone https://github.com/hackclub/scrapyard.git`)
- install the dependencies using `npm install`
- run `npm run dev`
